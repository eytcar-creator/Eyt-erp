# E.Y.T Catalog & B2B Order Portal v1

پرتال مشتری E.Y.T برای کاتالوگ، سفارش‌گیری B2B و پیگیری سفارش.

## دامنه هدف

`eyt-catalog.ir`

## جایگاه در اکوسیستم E.Y.T

- `eyt-car.com`: هویت رسمی برند
- `eytparts.ir`: فروش و بازار داخلی
- `eyt-catalog.ir`: کاتالوگ + B2B + سفارش‌گیری + پیگیری تولید

## جریان سفارش

ثبت سفارش → تأیید فروش → آماده تولید → در حال تولید → QC → بسته‌بندی → آماده تحویل → تحویل

## وضعیت پیاده‌سازی

این commit، UI/PWA اولیه قابل اجرا را اضافه می‌کند. برای عملیاتی شدن چندمشتریه باید UI به API موجود ERP متصل شود و احراز هویت، RBAC، Product Master و وضعیت‌های واقعی تولید از Backend خوانده شوند. قرارداد تولید موجود در `api/production/openapi.yaml` مرجع اتصال است.

## اصل معماری

پرتال نباید Master Data مستقل بسازد. کد محصول، SKU، UUID، BOM و وضعیت تولید باید از هسته ERP E.Y.T مصرف شوند.
