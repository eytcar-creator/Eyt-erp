# ثبت اولیه خانواده‌های محصول E.Y.T
نسخه: 1.0  
وضعیت: ثبت اولیه برای تطبیق با کاتالوگ واقعی  
تاریخ: 2026-10-22

## قواعد
- این فایل، ثبت خانواده است و جای Product Master یا پرونده فنی قطعه را نمی‌گیرد.
- خانواده‌ها با Category Tree و Master Data فعلی ERP هم‌راستا نگه داشته می‌شوند.
- محصول جدید، SKU، UUID یا مشخصه فنی به‌صورت حدسی ایجاد نمی‌شود.
- «نیازمند تطبیق» یعنی خانواده/زیرخانواده باید با کاتالوگ و سابقه واقعی تولید تطبیق داده شود.
- «سه‌شاخ» در کاتالوگ E.Y.T وجود ندارد و نباید اضافه شود.

## زیرخانواده‌ها/فرآیندهایی که باید بررسی شوند
این موارد نامزدهای دسته‌بندی‌اند، نه اعلام موجودی قطعی:
- تنه سیبک فرمان
- تنه سیبک طبق
- بال‌پین سیبک فرمان
- بال‌پین سیبک طبق
- میله قرقری
- فنجولی قرقری
- اجزای فورج موجگیر
- بوش‌ها: کاور بیرونی، بوش داخلی، کائوچو و مجموعه کامل، هرکدام طبق طراحی واقعی
- دسته‌موتور و مجموعه فلز/کائوچو
- گردگیرها و قطعات لاستیکی
- کیت‌های جلوبندی با BOM تأییدشده

## قاعده شناسه و ثبت محصول
1. ابتدا محصول فیزیکی واقعی شناسایی و با رکورد موجود تطبیق داده شود.
2. Product UUID مرجع ERP حفظ شود؛ SKU شناسه تجاری/انبار است.
3. برای هر محصول، کاربرد خودرو و OEM reference جداگانه و با وضعیت تأیید ثبت شود.
4. چند کاربرد برای یک قطعه فیزیکی به‌تنهایی دلیل ساخت رکورد فیزیکی تکراری نیست.
5. Batch ID برای هر نوبت تولید مستقل از Product ID است.
6. هر مشخصه نامعلوم با «فاقد اطلاعات» یا «نیازمند بررسی» ثبت شود؛ حدس مجاز نیست.

## اطلاعات لازم برای تکمیل ثبت
- خروجی فعلی Product Master و Category Tree
- فهرست SKUها و کدهای موجود، بدون ساخت مجدد شناسه
- نگاشت محصول به خانواده و زیرخانواده
- وضعیت تولید داخل، پیمانکاری یا بازرگانی
- Fitment/OEM reference با منبع و سطح اطمینان
- وجود/وضعیت نقشه، BOM، Routing و QC plan
